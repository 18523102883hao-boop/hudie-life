# 制作交接｜先读此文件

日期：2026-11-12。接手角色：商业内容策划、招商销售、实体商家运营和演示设计。

## 用户最终要求

把所有会议、思维导图、业务推进材料与“站在商家/代理商角度”的思考融合进新版PPT及宣传册。对方会问的问题、反对、要求修改的地方、替代方案与回应，必须影响正文的叙事和合作方案，不是把长FAQ放到最后了事。

旧演示用户反馈：内容位置错误、重叠、排版及格式细节不到位。原来的结构校验和页数检查没有证明视觉质量，不能继续把“导出成功”当成合格。请重新设计，不直接修补旧模板。

## 目标与范围

- 城市伙伴：理解平台可交付价值，核对投入与收益，愿意提供真实资源并进入可评估试点；政策和证据齐后才转正式付费合作。
- 实体商家：理解门店利益，选出一个适合且有贡献的套餐，确认结算、推广与履约，愿意做有限试点。
- 风格：简洁商务、中文、手机和投影可读；无虚构案例、图库照片、假系统截图。
- 不承诺确保成交、销量或回本。说服应依赖具体交付、清楚算账、责任与退出。

## 阅读优先级

本次用户要求 → handoff中的融合与制作要求 → sources原始会议的事实定位 → archive派生分析与旧文案。会议口述不是功能验收或正式政策；新建议也不是用户批准的商业承诺。冲突必须写进决策表，不擅自选一个数。

建议顺序：01总底稿 → 02逐页 → 03矩阵 → 04验收 → 07待补；再读三份会议全文、思维导图，以及archive内业务梳理、政策表、谈判手册、讲稿、商家手册和证据索引。长文件分段读并记录范围，不能把摘要冒充已读全文。

旧包的来源文件位置描述仍保留历史形式；实际原文现位于sources/meetings。archive里的00导航包含本机路径与旧预览端口，只是历史记录，不表示另一台机器可打开。
