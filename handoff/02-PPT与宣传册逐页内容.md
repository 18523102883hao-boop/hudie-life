# 新版PPT与宣传册逐页内容

用法：以下为融合后的内容任务和可直接改写的短文案。页面编码用于03矩阵；页数变化须保留编码到实际页号的映射。不要把整行文字原样塞进一页。每页补充讲稿：听众顾虑、解释、证明资料、追问与下一步。服务尚未定稿时使用共同确认的表达。

## A 城市伙伴招商PPT｜P01—P16主讲

| 编码 | 页面标题及可用正文 | 图示与说服任务 |
|---|---|---|
| P01 | 让本地商家资源，形成可核算的持续合作。副题：蝴蝶生活城市伙伴合作交流；先选品、算清账，再共同试点。 | 简洁文字封面；指向经营而非招下级 |
| P02 | 您已有商家资源，合作还需要补齐什么？商品适合卖、推广有人做、履约接得住、订单对得清。 | 四个经营问题；先认可对方已有能力，不靠人口规模施压 |
| P03 | 平台的价值，落在具体工作上。共同确认商品整理、订单工具、核销培训、对账与运营协作；每项写清交付和验收。 | 平台拟协作/伙伴负责/商家负责三方图；尚未验证工具不写成已上线 |
| P04 | 按您愿意承担的工作选择合作。资源推荐、商品运营、城市运营，投入和权益分别确认。 | 三类身份卡；回答只介绍资源是否可做，非正式价格套餐 |
| P05 | 同一门生意，两条交易路径。A视频号商品/直播交易；B内容或广告进入小程序。渠道、成本、售后逐条核对。 | 两条简图；社群/图文/其他入口归B，广告标付费；全部功能按实开范围 |
| P06 | 先选一个值得长期卖的套餐。用户愿买、门店有贡献、内容讲得清、时段与履约可控。 | 选品四条件，酒店/聚餐/休闲仅为候选品类，不用未签约品牌 |
| P07 | 189元售价，29元价差，仍需扣足费用。示例：结算160、佣金9、渠道11.34、支付0.567、变动成本1，剩7.093。 | 假设瀑布图；费率与非净利标识紧邻；完整公式放讲稿 |
| P08 | 先看一单贡献，再看需要多少订单。示例伙伴每单5.6744；月投入3000需529单；含6000报酬共需1587单。 | 门槛情景而非收入预测；解释为何共享人员更合适；税费等未扣 |
| P09 | 自己带来的流量，也要按实际服务算账。工具协作、约定运营、额外推广分别确认；所有费用一表列清。 | 服务/交付/承担方/费基四列示意；费用冲突在内部，不把3万或3500标成报价 |
| P10 | 商家资源怎样登记，持续投入怎样保护？确认存量客户、有效登记、服务责任、保护期和跨城冲突。 | 简单登记—核对—确认—争议处理流程；未定期限不填“永久” |
| P11 | 区域权利与双方投入一起约定。先明确城市/品类/商圈和期限，再以双方交付评估扩大合作。 | 双方里程碑；回答长期独家诉求，不展示已经授予的地图 |
| P12 | 不只看支付，还要看核销、退款和到账。每笔订单有关联明细，每项扣费能核对。 | 订单证据链；无后台时标“流程示意”，讲稿说明实际链路待验收 |
| P13 | 从限定投入的试点开始。确认范围与预算—按约交付—核对真实结果；再决定继续、调整或扩大。 | 三阶段时间轴；观察期覆盖核销结算，不强制30天完成所有长券 |
| P14 | 暂停和退出，也应事先讲清。停止新售、存量履约、已发生佣金、未交付费用、资料权限分别处理。 | 退出五项清单；回应平台改规则/技术故障，补异常联系人确认项 |
| P15 | 适合一起做的伙伴，有资源，也愿意经营。能提供真实供给、指定运营人、核对账目并协作售后。 | 资源/人/预算/责任四项自查；只想获客全部外包的需重新选身份 |
| P16 | 带一个真实商家，开始一次合作评估。请提供城市、品类、可对接商家和投入条件；下一步核对商品、系统与试点安排。 | 明确CTA；联系本次邀约人，无二维码占位 |

### 城市伙伴备用页P17—P20

- **P17｜不同合作条件怎样谈**：按成交合作、分阶段服务付费、工具型、资源推荐型四种“可讨论选项”。费用、交付和资源保护需双方确认，不能自动视为免收费政策。
- **P18｜三个场景分别算**：自然分享18.433、广告后6.433、视频号7.093，均沿用假设；提醒广告不是免费流量，渠道费与支付费是否重叠待合同核对。
- **P19｜合作前看哪些证据**：主体、服务表、准入/费率、实际订单与到账、规则与退出。没有的明确列补证据动作，不虚构公章/证书。
- **P20｜关键问题怎么回答**：为何收费、资源归属、独家、收益、故障/数据、退出。每题只给一句原则，详细答案放内部手册；来源索引置讲稿。

## B 商家合作PPT｜M01—M12主讲

| 编码 | 页面标题及可用正文 | 图示与说服任务 |
|---|---|---|
| M01 | 让一个好套餐，多一种获客方式。先选品、再算账、小范围试售。 | 直接表达合作提议，文字品牌 |
| M02 | 先从您想改善的一个时段开始。填补闲时、推广适合人群的套餐、减少接待误解；选定一个主要目标。 | 三个真实经营问题；不暗示一定新增客 |
| M03 | 已有渠道继续经营，新合作先找补充价值。可讨论独立套餐、指定时段和有限库存；不要求全店普降价。 | 同规格/不同套餐要区分；回答已有美团抖音与品牌价格担忧 |
| M04 | 一个套餐，先把六件事写清。人数、内容、价格、可用时段、预约、额外收费。 | 产品信息卡示意，不用虚构已签酒店；不靠强制到店加价补亏 |
| M05 | 每单拿到多少，先于上架确认。示例结算160、增量履约成本140、贡献20；仍需承担固定成本和税费。 | 三项简图；全部标假设；增量人工/损耗要纳入实际核算 |
| M06 | 选择适合的入口，也明确谁来推广。内容带货、小程序分享或广告，按实际开通与约定安排。 | 两路径与责任；不保证免费拍摄、上架即直播或平台供流量 |
| M07 | 您提供好产品，合作工作逐项落实。门店：库存/接待/核销；团队拟协作：整理/上架协调/约定推广/培训复盘。 | 双方责任＋可选服务；负责人、交付日期、预算共同确认 |
| M08 | 前台能顺利接待，合作才算跑通。购买提示—预约—核销—异常求助，先演练再扩大。 | 四步流程，库存上限/停售机制；未验收不画假界面 |
| M09 | 退款与到账，有清楚的对应路径。支付、核销、可结算和实际到账分别核对；售后按原交易处理。 | 结算时点图＋异常入口；不填无证据的T+1或即时到账 |
| M10 | 把一次试售的投入限制清楚。指定SKU、库存、时段、预算与人员；新增付费事项重新确认。 | 有边界的试点卡；可暂停新售，已售订单按约处理 |
| M11 | 复盘看门店真正得到什么。支付、核销、到账、贡献、额外工时、新老客/未知；一起决定继续、调整或停止。 | 六指标；不把总销量等同增量，不把一次爆单当长期证明 |
| M12 | 约15分钟，先确认一个候选套餐。请提供门店、商圈、套餐与负责人，我们一起把结算和接待条件说清楚。 | 清楚CTA，不以当场交费作为唯一目标 |

### 商家备用页M13—M15

- **M13｜常见问题**：销量、额外收费、已有平台、价格、结算、退款，短回答并指回主讲证据页。
- **M14｜您的合作偏好可以这样讨论**：闲时产品/专属套餐/限量按成交；包销另评估，不能默认接受；用户自愿复购及数据按职责授权。
- **M15｜品类沟通清单**：酒店儿童/节假日；聚餐份量/包间/茶位；休闲预约/器材/天气。来源与示意说明进页脚和讲稿。

## C 城市伙伴宣传册｜B-P01—B-P06（A4竖版6页）

1. **B-P01 封面与提议**：“把本地商家资源，经营成可核算的合作。”解释适合谁、共同评估什么，CTA留下城市与一个商家线索。避免大数字填充封面。
2. **B-P02 合作究竟多了什么价值**：整合P02/P03/P04，说明工具协作、运营服务、伙伴工作与三类合作身份。回应“凭什么收费”“只介绍行不行”。
3. **B-P03 怎么成交、每单怎么算**：整合双路径和189元假设图，区分费用与可分配贡献；补一句“投入3000的订单门槛约529笔，假设情景，非预测”，不塞完整瀑布长表。
4. **B-P04 服务、资源和区域权益**：按实际服务确认费用；资源登记、存量排除、期限、争议；区域权利与双向投入一起确认。回答自有流量分成与独家需求。
5. **B-P05 如何试点，遇到问题怎样退出**：阶段合作、预算、交付验收、对账、故障与暂停、存量订单清算；报价未定不虚填价格。
6. **B-P06 六个关键问答＋下一步**：平台价值、赚钱门槛、保护资源、支持、结算、退出。结尾说明带一个商家做评估、联系本次邀约人；条件以双方书面确认及实际开通为准。

## D 商家宣传册｜B-M01—B-M04（A4竖版4页）

1. **B-M01 从一个门店经营目标开始**：“让一个好套餐，多一种被看见和购买的机会。”整合M02/M03，强调闲时/差异产品、库存可控；可配一个无商家品牌的产品信息示意。
2. **B-M02 套餐、门店贡献与推广分工**：六项产品信息、160-140=20假设贡献、双方工作、拍摄达人广告另确认，回答低价与隐性支出。
3. **B-M03 前台接待、结算与售后**：购买预约核销、到账四时点、退款及异常联系人、停售与存量履约、顾客自愿复购与数据职责。没有真实后台不留截图空槽。
4. **B-M04 试售确认＋关键问答＋约访**：有限投入、观察期、六项复盘；销量不承诺、已有渠道可继续、可讨论独立SKU与限量合作；明确下步是提供一个候选套餐。

### 商家一页精简版

上半：一句合作价值＋适合的三类门店；中部：选品/算账/约定推广/履约四项；下半：三步试点、明确费用边界和CTA。必须包含“按实际开通和书面约定”“不承诺销量收益”，但不要让小字占据主体。A4一页，正文可读，不把四页文字压缩到一页。

## 内容与宣传的边界

内部手册可以讨论3万/3500冲突、让步范围、单笔薄利与识别拒绝；对外转化成明确费用确认、投入门槛和试点方式，不暴露内部谈判底线，也不隐瞒费用或已知限制。26组异议通过主讲、备用页、宣传册、讲稿共同覆盖；主讲不能承担所有长问答。
