- 结算周期、收款主体、费用范围、退款规则未最终确认，不填造T+N。
- 188/150/90/60仅算账示例；差额不再叠加重复佣金；贡献非净利润。
- 微信与WeChat合并月活14.18亿为腾讯2025年末账户口径，不能解释为本项目流量或独立人数。来源见PPT第15页。
- 不将“美团均收年费”“抖音综合成本统一30–40%”“微信保证红利”当作行业事实。
- 六类渠道是按资质与排期安排的触达方式，不是发布商品自动同步所有渠道。流程图不是系统接口架构。
