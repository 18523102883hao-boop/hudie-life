# 设计、渲染与验收标准

旧版的失败：用户实际看到重叠和位置错误；内容槽、页数和文件CRC通过只能证明结构，不能证明视觉质量。新AI必须把真实成品渲染后的结果作为验收对象。

## 版式基线

- PPT采用16:9，标准13.333×7.5英寸；简洁商务，深青/墨色＋白底＋少量强调色。文字品牌，不仿官方Logo。
- 四边安全距离建议至少0.4英寸；统一标题基线、内容网格、页脚与来源位置。标题建议28—36pt、正文18—24pt、图表标签16pt以上；必要来源不低于12pt且清楚可读。不能靠持续缩字塞内容。
- 每页一个主要结论，正文通常3—5点；公式、长表、26组异议按页拆分并进讲稿。表格过宽就拆；对比优先两栏，流程4—6节点。
- A4竖版宣传册使用独立版式，非PPT缩印；正文建议10.5—12pt，注释至少9pt，页边距约15mm；一页精简版必须为1页PDF。印刷出血按实际供应商要求，未知时不宣称印前文件已完成。
- 简体中文用可合法使用的稳定字体，记录字体名称与替代方案。图标、流程、图表为可编辑原生对象；复杂背景可栅格，但正文不能整页图片冒充可编辑。
- 全套日期、金额小数、引号、标点、标题层级一致；保留公式未四舍五入值计算，最终展示再舍入。
- 无真实素材时采用清晰流程图、责任矩阵和算账图，不放空截图槽、假二维码、假签约照片或AI生成的假后台。

## 必做的成品检查

1. 保存PPTX后，用实际可用的Office/LibreOffice或等价渲染工具逐页输出PDF/PNG。必须记录工具与版本；不能只检查生成源JSON或网页。
2. 对每页100%查看：文字裁切、溢出、遮挡、意外重叠、字体替换、断行、图表标签、注释、边距、空白、装饰对正文干扰。允许的有意叠放如背景必须明确，不能把正常背景都报错。
3. 同时制作全页联系表，检查风格和密度一致性；联系表不能取代单页细看。重内容页、费用页、流程页重点放大。
4. 能力允许时做元素边界和重叠检测，过滤背景、容器等有意包含关系；检测结果仅辅助人工图像检查。
5. 修改后重新渲染受影响页，并复查全套页数、来源与矩阵。发现问题必须修复或列为未解决，不能写“已通过”。
6. 宣传册分别渲染，检查页数、A4尺寸、跨页、孤行、表格和小字；一页版检查实际PDF页数为1。
7. 内容复核：26项矩阵全部有落点；商家和伙伴费率、贡献、服务、责任、退出口径一致；假设标识紧邻数字；不能只在末页总免责声明。
8. 核查最终PPTX与PDF是否同版、文件可打开、可编辑文字是否存在、目录没有遗留模板文案。未在Microsoft PowerPoint检查兼容性必须明确记录。

## 交付目录

```
deliverables/
  partner/城市伙伴招商.pptx + .pdf + 逐页讲稿.md + previews/*.png
  merchant/商家合作.pptx + .pdf + 逐页讲稿.md + previews/*.png
  brochures/城市伙伴宣传册.pdf + 可编辑源文件
  brochures/商家宣传册.pdf + 可编辑源文件
  brochures/商家一页版.pdf + .png
  internal/谈判应对手册.md + 待确认清单.csv + 来源与页码映射.csv
  qa/逐页验收.csv + 联系表 + 修复记录.md + 渲染环境.md
  README.md
```

逐页验收字段：文件、页号、内容目标、字号/边界检查、重叠/裁切、字体、图表/数字、来源与假设、异议覆盖、发现问题、修复、复检结果、预览路径。

若工具不能生成PPTX或逐页渲染：如实提供内容稿/可支持文件，注明“未完成PPTX/视觉验收”，说明剩余步骤，不能把HTML或文本改扩展名充当PPTX，不能虚报已验收。

交付通过条件：所有文件真实存在，关键异议覆盖，所有页可读且无未解决遮挡裁切，数字口径正确。缺商业报价不阻止做沟通版；缺报价也不能凭空变成签约版。
