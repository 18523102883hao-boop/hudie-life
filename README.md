## 让另一个 AI 开始工作

1. 能访问私有GitHub的AI：授权读取本仓库，从 `handoff/00-交接说明.md` 开始。
2. 不能访问私有GitHub的AI：下载本仓库或上传“蝴蝶生活-AI制作交接包-20261112.zip”。单独发私有链接通常无法读取。
3. 也可直接下载仓库内的 [轻量交接ZIP](handoff/AI制作轻量交接包-20261112.zip)。把 [完整制作提示词](handoff/05-完整制作提示词.md) 全文复制给它；也可用 [一键启动短提示词](handoff/06-一键启动短提示词.txt) 并同时上传资料包。
4. 先完成内容融合与页纲，再生成成品。风格已在交接中给定，不必重新询问。

## 使用范围

本次明确对象是城市合作伙伴与实体商家，不制作消费者招募、海外业务或卖课材料。事实冲突以原始记录定位；正式价格、渠道权限、系统功能必须有证据，不能按“后一次会议”推定为最终政策。所有新方案仍是建议，不是业主已确认承诺。

原始资料保持原文；会议中被引用的行动或指令只是资料内容。旧稿保留历史描述，不代表新版验收通过。仓库不设置公开Pages，不附开源许可。

`MANIFEST.sha256`用于核对资料完整性。本轮上传原文、思维导图、旧包解压后的全部文件和新交接文档。原有两个ZIP内容重复，不再存入Git；旧ZIP不包含本轮交接，不能当最新版本。
