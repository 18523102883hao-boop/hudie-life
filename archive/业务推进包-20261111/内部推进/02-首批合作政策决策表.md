# 蝴蝶生活｜首批合作政策决策表

2026年11月11日 · 待负责人定稿，不是已生效报价或合同

## 1. 先分清三种合作身份

| 身份 | 提供什么 | 获得什么 | 不能混用的承诺 |
|---|---|---|---|
| 商品合作伙伴 | 商家和可售套餐，持续维护履约 | 按实际商品经营贡献取得约定分成 | 免费开后台不等于免费取得城市独家权 |
| 城市运营伙伴 | 本地供给、内容、渠道、商家运营及售后协作 | 经约定的区域经营与服务收益 | 城市名额不等于股权；分成不等于保底回报 |
| 推广者/达人 | 真实内容、推荐与成交 | 对符合条件的实际订单取得佣金或自用优惠 | 用户绑定不等于永久无条件收益；不按拉人头计酬 |

建议先采用商品合作试点，城市运营权另签清晰协议；不把招募下级作为收益主轴。城市、区县、商家资源归属冲突须先有书面规则。

## 3. 推荐的试点条款清单（讨论稿）

- 范围：指定城市/商圈、指定商家及SKU，明确是否独家；默认仅沟通试点，不推定独家。
- 期限：可讨论30天观察期，但应覆盖商品核销和结算周期；记录中“三个月”是另一种提议，需选择后签字。
- 供给：商家授权、履约能力、素材使用权、套餐明细、库存与撤架通知。
- 运营：每周谁出内容、谁审核、谁发布、谁跟单；平台公共直播与定制拍摄分开约定。
- 费用：一张费用附件写完，附两种订单例算；分成基数和小数舍入一致。
- 归属：保护已登记且有实质跟进的商家线索；跨城连锁、存量客户、冲突仲裁有时限。
- 数据：伙伴可查看与本人合作相关的真实经营和收费明细，按职责授权，隐去无关用户个人信息。
- 售后：消费者入口、商家处理人、平台升级联系人；停售不影响存量订单履约。
- 退出：未使用服务费处理、应付佣金和货款结清、未核销券、资料移交与账号权限撤销。
- 变更：清楚通知、公示与必要过渡，不使用“最终解释权”替代规则；已发生订单按约处理。

这是一份商业谈判清单，不替代最终合同。是否构成特许经营等安排，要按实际品牌授权、经营模式、收费和管理关系审查，不能靠把“加盟”改称“代理”解决。

## 4. 单笔模型使用说明

配套《渠道算账演示.csv》仅用于对照，金额均为假设。商家结算额、渠道费、支付费、推广佣金、退款/赔付损失分别列示；如果第三方渠道已含支付费，支付费另列填0，避免重复扣。

建议分钱顺序：先确认订单满足结算条件 → 核对退款/冲正 → 结清约定商家款及渠道成本 → 按定义算可分配贡献 → 按签约比例计算双方份额。负贡献品不自动用加盟费补贴。

“利润分成”和“流水分成”必须选定或明确互斥适用范围。例如189元实收的5%是9.45元，而上述视频号例算的全部可分配贡献只有7.09元；再扣9.45元会亏损2.36元。这里说明混用口径的后果，并非认可5%的政策。

## 5. 对外说法统一

| 容易误导的原说法 | 可用于沟通的表达 |
|---|---|
| 零成本、没风险、一定是增量 | 先用约定套餐做小范围试点，按实际订单与费用核算效果 |
| 干一年吃十年、月入七八万 | 收益取决于商品、推广、核销、结算及成本，不承诺收益 |
| 腾讯官方项目、独家通道 | 蝴蝶生活是独立业务；具体渠道能力以实际准入与演示为准 |
| 免费帮所有商家一直直播 | 可申请平台选品与直播排期，具体服务见确认单 |
| 约2万达人就是2万活跃用户 | 会议提及历史达人基础，当前活跃与可触达人数尚待核验 |
| 只要接了持牌支付就完全合规 | 需核验主体、合同、进件和实际资金路径，再说明结算机制 |
| 永久绑定，平台可随时不给钱 | 归因、佣金生效与调整规则提前明示，已发生订单按约结清 |
| 0元兑换单不需要退款或投诉 | 兑换记录关联原付款订单，售后责任和原渠道退款路径清晰 |

以上修正针对会议实际出现的问题，不属于对现有系统的违法认定。
