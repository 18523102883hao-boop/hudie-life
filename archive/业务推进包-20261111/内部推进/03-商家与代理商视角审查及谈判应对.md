# 蝴蝶生活｜商家与代理商视角审查及谈判应对

2026年11月11日｜内部谈判准备｜建议稿，未经负责人批准，不是对外承诺

本次复核已制作的政策决策表、商家洽谈手册和招商逐页讲稿，并沿用前次会议证据边界。以下是对谈判对象可能反应的推演，不是真实访谈结果，也不新增市场或平台事实。

## 一、先把预期目的拆成可以达成的动作

暂按“获得能持续经营的试点商家和城市伙伴，最终形成真实交易与收益”理解你的目的。首访拿到候选套餐与负责人，第二次确认经济账及试点条件，验证交付后扩大或付费。每次谈判有明确下一步，比只拿到口头认可更有价值。

如果你的首要目标是近期收取代理费，当前证据不足会直接影响成交和后续稳定性；要先把收费对应的真实交付做出来，而不是用长周期回报说服对方。准备充分不能保证成交，合作是否成立仍取决于需求、实际能力、成本和执行。

## 二、从对方立场给现方案打判断

**商家最可能的判断：**多一个渠道可以，但为什么我要为了尚未证明的流量让出毛利、训练前台，还承担差评和退款？

**代理商最可能的判断：**商家我谈、内容我做、客户我带、售后我管，那我为什么还要交钱和分成？你提供的能力能否替代我现有工具，或者产生足够的新收入？

现方案的优点是账与责任透明，没有夸大销量；不足是“具体按约”“待实际开通”很多，却缺少可直接购买或接受的完整合作产品。透明是基础，明确的交付才是成交理由。

需要先优化七件事：

| 优先级 | 当前缺口 | 对方为何犹豫 | 建议修改 |
|---|---|---|---|
| P0 | 系统能力未实测 | 我在替你测试，还要承担客户问题 | 至少演示一条真实购买—核销—退款—结算路径，列出可用范围 |
| P0 | 收费与分成未统一 | 你是否会谈完继续加价 | 一页费用表，列费基、承担方、上限、是否含支付费及退款处理 |
| P0 | 服务包不具体 | “推广支持”到底是什么 | 写明负责人、交付物、时间、验收及未交付处理；只填写可兑现事项 |
| P0 | 平台价值缺证明 | 我付的是系统费还是流量费 | 分别展示工具省下的具体工作与已安排的运营服务，不混卖 |
| P1 | 试点仅有期限，没有投入上限 | 即使不交费，也会消耗人力和毛利 | 限SKU、库存、预算、接待时段、人员投入；新支出重新确认 |
| P1 | 资源归属笼统 | 我开发的资源会被绕过 | 商家登记、既有客户排除、有效跟进、争议处理、退出结算写清 |
| P1 | 没有比较合作前后 | 有订单也可能只是老客换渠道 | 记录是否首次消费、闲时填补、额外成本；无法识别的标未知 |

不建议继续把大生态用户规模当核心说服页。保留作背景即可；面对商家先讲门店的一个具体经营问题，面对伙伴先讲其可验证的经营账。

## 三、商家可能提出的12组问题、反对与应对

| 商家的问题或反对 | 他真正担心什么 | 他可能提出的方案 | 建议回应与可交换条件 |
|---|---|---|---|
| 1. 你们到底能带来多少客人？没有用户为什么找我？ | 浪费准备与培训时间 | 不收费，先带客再谈 | 承认当前没有可靠销量预测；先提供实际渠道与排期，再谈限量测试。可以不收尚未交付的推广费，不能承诺无限免费服务 |
| 2. 我已经做美团、抖音了，为什么再开一个？ | 重复操作、老客转成低价订单 | 只卖闲时或独立套餐 | 接受差异时段/规格试点；比较同规格实际到账与增量成本，不靠贬低其他平台说服 |
| 3. 结算价太低，我不赚钱 | 低估食材、损耗和增量人工 | 保底结算额，超出部分你们赚 | 先确认最低结算额，再反算渠道空间；调整内容、库存、时段，不能靠隐性到店加价补亏。所有成本扣完无空间就不做 |
| 4. 别公开低价，老客看了会找我 | 价格体系及品牌受损 | 专属套餐、会员权益、非高峰票 | 用真实不同的内容与限制设计；商家审核文案，禁止未经确认声称最低价 |
| 5. 你们先买断100份，我才给底价 | 把需求风险转给你 | 预付款、包销、保量 | 优先建议限量代销或阶段解锁库存；未经测算不承诺包销。若讨论预购，另算有效期、退款、未用损失与资金占用 |
| 6. 钱多久到？平台出事怎么办？ | 现金流与资金路径 | 核销后短周期结算，提供明细 | 用真实账单证明收款主体和到账节点；没有能力就不要答应即时到账。对方要求无法满足时，先停止付费上架 |
| 7. 退款、爽约、节假日爆单谁管？ | 现场拥堵及差评 | 预约、每日限量、停售权 | 提前写入商品页；限量和暂停机制先验收，再开放库存。售前提示、履约和系统故障分别分责，不一概推给门店 |
| 8. 前台又要学一个系统？ | 培训与错误核销 | 你负责培训，保留快速求助入口 | 指定一名门店对接人；交一页核销指引、做一次员工演练、约定异常处理人，核销路径过重则缩小试点 |
| 9. 谁拍谁播？说免费后来又加钱怎么办？ | 服务缩水、被迫追加预算 | 全包价、无新增收费 | 给基础与可选服务清单；可以约定预算上限，但达人/广告/专场不得口头无限包含 |
| 10. 客人以后归谁？你会不会导去同行？ | 顾客关系受损 | 商家自己留客，不许外导 | 区分商家服务关系、平台营销与用户自愿授权；说明谁能看何种数据，不能承诺把消费者个人资料全部交给商家 |
| 11. 没效果怎么办？能随时停吗？ | 沉没成本和长期绑定 | 随时下架、无独家、失败退费 | 可讨论暂停新售与不自动续费；存量券履约、已交付服务、应退未交付费用分别处理，不能以停售免除已售责任 |
| 12. 我可以直接找达人或其他工具，为什么用你？ | 中间环节没有价值 | 只买上架/核销工具，推广自己做 | 提供工具协作与运营服务两种边界；如果你没有可证明的选品、渠道协调或对账价值，就先补能力，不用“生态红利”掩盖 |

### 商家现场可直接说的四段话

**对方要保销量：**“您担心花了时间却没有效果，这个担心合理。现在我不能给您一个没有依据的销量承诺。我能先明确的是谁做哪些推广、什么时候交付、您最多放多少库存和投入多少。我们按这些条件做一次可停止的测试，结果和到账一起复盘。”

**对方嫌结算低：**“先从您愿意长期接待的结算额倒推。如果这个价格覆盖不了门店成本，就调整套餐或时段。我们把渠道费用扣完再看是否还有合作空间，没有空间就换品，不让您用到店加价补洞。”

**对方说已经有渠道：**“已有渠道做得好是优势。我们先找一个您希望填补的时段，只拿一个独立套餐测试。后面比较实际到店、贡献和工作量；如果只是把老客搬了个地方付款，就不值得扩大。”

**对方迟迟不决定：**“目前最影响您判断的是结算、推广安排，还是前台执行？我们先解决这一项。条件合适的话，下一步请您指定对接人，一起确认一个候选套餐；还不用一次把全店商品都上架。”

## 四、代理商可能提出的14组问题、反对与应对

| 代理商的问题或反对 | 他真正担心什么 | 他可能提出的方案 | 建议回应与可交换条件 |
|---|---|---|---|
| 1. 所有活我做，你凭什么收费分成？ | 平台贡献小、重复收费 | 免入门费，只按成交分 | 拆明工具、培训、运营服务与持续维护；仅对真实交付报价。平台若只提供工具，就按工具价值谈，不能同时售卖不存在的流量 |
| 2. 3万和3500到底哪一个？ | 价格随人变、早交钱吃亏 | 最低价或价格保护 | 正面承认旧会议是不同设想，提供统一版本、服务差异和有效期；不要临场编“内部名额价” |
| 3. 每月能赚多少？多久回本？ | 投入机会成本 | 保底收入、回本退款 | 提供情景测算与真实成本字段，不作收益保证；观察其可执行资源，先试点再增加固定投入 |
| 4. 为什么按利润分？成本全由你定 | 不透明成本侵蚀分成 | 按净核销额固定比例 | 可比较两种方案：可审计的贡献分成，或能覆盖成本的固定服务费/费率；选一种并写清互斥范围，不能暗中叠加 |
| 5. 我要全城独家五年 | 投入被其他伙伴稀释 | 长期独家、无考核 | 可讨论先登记资源，完成双向里程碑后取得限定区域和期限的权利；考核也要绑定平台支持，避免单方义务 |
| 6. 我带的商家以后被总部直接签怎么办？ | 被绕过、失去积累 | 长期客户保护与续单佣金 | 明确有效登记、存量客户、保护期、持续服务条件与争议证据；不随意抹去已发生订单权益，也不承诺无限期占有客户 |
| 7. 我自有流量为什么也分给平台？ | 为自己的资源重复付费 | 自有渠道低费率或固定费 | 按真实服务差别讨论工具型方案；必须覆盖系统、结算协作和维护成本。带客方和服务方分别记录，避免口头争归属 |
| 8. 商家、达人、总部、区县都要分钱，剩多少？ | 多层抽佣后无利润 | 取消一层或总费用封顶 | 当场展开同一订单全链条；先定总可分配空间，再分配角色。某层没有持续服务价值，就不增加该层 |
| 9. 总部到底派多少人、带几场直播？ | 口头支持不落地 | 明确场次、交付和未完成补救 | 只填写可排班资源；公共选品不能等同专场保证。可承诺交付物与响应目标，不能保证播放量或销量 |
| 10. 技术故障或渠道关闭怎么办？ | 业务依赖单点 | 服务保障、费用暂停、退出权 | 列明异常响应、停售、对账导出与存量订单安排。备选路径要先验证，不能承诺任何时候都能无缝切换 |
| 11. 数据能看吗？佣金被调怎么办？ | 黑箱结算和规则变动 | 可导出账单，变更前通知 | 展示本人相关订单及扣费样表，约定核对与争议时间；明确新旧订单的适用版本，不用最终解释权搪塞 |
| 12. 做不下去，钱和商家怎么办？ | 退出成本 | 未交付服务退款、继续收存量佣金 | 按已交付服务、未交付部分、存量订单和后续维护责任逐项清算；退出不能直接清空应付款，也不无限承担未来服务 |
| 13. 我只介绍商家，不拍内容和做售后行吗？ | 岗位与能力不匹配 | 纯推荐合作，一次性或有限期报酬 | 单列推荐合作身份，明确有效线索标准与结算事件；不把不愿运营的人包装成城市运营商 |
| 14. 我不代理，自己开小程序不行吗？ | 自建可能更可控 | 技术采购、白标、自营 | 比较其实际要承担的商品、渠道、核销、对账、售后工作。若自建更适合，接受技术或单品合作；没有证据不编造自建高成本 |

### 代理商现场可直接说的四段话

**对方质疑总部价值：**“您说得对，不能因为挂了平台名字就持续收费。我们把您做的工作和我们交付的工作逐项摆出来，分别计算。您不需要的服务不打包硬卖；目前拿不出证据的能力也不作为收费理由。”

**对方要长独家：**“您需要保护投入，我们也需要区域有人持续经营。可以先把已登记商家的权益写清，再按双方完成的工作扩大保护范围。平台支持未兑现的影响也要写进去，不把所有考核都压给您。”

**对方要回本保证：**“我能保证按约交付，不能保证市场一定买单。我们可以把一次大投入拆成阶段交付和验收，让您在每个节点都有继续或停止的选择。先把单笔账和可执行量核实，才讨论扩张。”

**对方只想拿最低价：**“价格要对应服务和权利。同样服务采用同一口径；如果您自己承担内容、培训或部分运营，我们可以核算删掉这些服务后的方案。降价要对应工作减少或可核实的资源投入，不单靠口头承诺销量。”

## 五、对方可能给出的替代方案：接受什么，换什么

| 替代提案 | 建议态度 | 需要交换或补齐的条件 |
|---|---|---|
| 商家不交入驻费，只按成交结算 | 可讨论 | 限基础交付、明确结算价；定制内容与广告另定预算 |
| 商家让出闲时库存，不给全时最低价 | 优先讨论 | 产品页和核销严格执行时段；不要宣传全时通用 |
| 商家要求包销 | 慎重，不能作为默认让步 | 单独审批现金预算与未售损失，明确退款及有效期 |
| 伙伴零入门费，按实际服务/成交付费 | 可作为早期试点选项 | 限服务范围、指定责任人与投入、不赠送长期独家 |
| 伙伴交小额服务费，达成后抵扣 | 可讨论，未定价 | 费用对应交付、抵扣对象/期限/上限和失败处理全部写清 |
| 伙伴分阶段付款 | 优先讨论 | 按可验收交付触发，不按模糊“平台启动”触发 |
| 对方要全城独家 | 不直接承诺 | 先限定范围与期限，双向里程碑，明确未达处理及存量权益 |
| 对方只愿做资源介绍 | 单列合作身份 | 有效线索、重复线索、奖励触发、后续维护人分别定义 |
| 对方愿用自己的工具，只与你互供商品 | 可作为备用合作路径 | 核查商品授权、库存同步、退款与对账是否真能协作 |

让步原则：每次让步都说清“换来了什么”。减费用换较少交付或对方承担可验收工作；扩大服务换明确预算；扩大保护换实际持续投入。不要拿不存在的名额、虚构倒计时或未证实的同行成交施压。

## 七、算给代理商看：先看订单量门槛

沿用前包纯假设：一笔189元订单，扣完示例变动成本后的贡献7.093元，伙伴按80%分得5.6744元。这是固定成本和税费前的金额，不能称净利润。

若伙伴每月自行承担固定投入3000元，仅覆盖这一项就需要约529笔满足结算条件、能产生上述贡献的订单（3000÷5.6744向上取整）。若还希望获得6000元劳动报酬，则需约1587笔；仍未覆盖可能的额外税费及例算外损失。3000元和6000元均为讨论假设，不能用于收入宣传。

这暴露出关键问题：若实际单笔贡献接近该例子，招一个有工资与场地的独立城市团队，可能并不划算。优先考虑有现成商家业务、能够共享人员的伙伴；或者提升商品贡献、减少重复服务层级，再谈重投入的城市经营。不能靠提高加盟费掩盖订单经济性不足。

现场必须填四个数：每单实际贡献____；每月固定投入____；可执行的有效订单量____；退出前最大可承受投入____。如果对方只能凭愿望填写订单量，先做测试，不谈回本周期。

## 八、怎样判断是真异议还是委婉拒绝

- 有兴趣但缺证据：会主动要合同、账单、套餐条件，并愿意约下一次演示。给材料与明确时间。
- 有需求但条件不合：能说出最低结算、服务范围或预算。一起重算，必要时换方案。
- 没有当前优先级：一直说不错，却不提供商品、不指定负责人。询问是否暂缓，减少反复追问。
- 能力不匹配：只期待总部代做全部运营或只想招下级。改为推荐身份，或不合作。
- 不能成立的要求：必须保本、必须隐瞒收费、必须做虚假业绩。明确无法接受，停止推进该条件。

不要用更多话术强行覆盖最后两类问题。一次合适的“不做”，能避免后来更大的退款、客诉和资源消耗。

## 九、每次谈完必须拿走什么

商家：一个候选套餐＋可接受结算条件＋实际决策人＋下次确认时间。
伙伴：一个真实城市/品类场景＋可执行资源＋期望合作身份＋最关键的未决条件。
自己记录：对方原话、真实顾虑、所需证据、可交换条件、负责人、回复时间、下一次动作。

收口：“今天我们先确认已一致的三件事：____。还剩____需要核实，由____在____前提供。材料齐后，下一步是____；如果这项条件达不到，我们就调整方案或暂缓。”

## 十、下一次更新两套演示时的具体修改

商家版：把泛渠道介绍压缩，把“你提供什么、我们交付什么、最多投入多少”做成一页；用目标门店真实套餐替换假设例算；增加前台操作、退款、暂停及结算样例。未验收前只讲流程，不伪造界面。

招商版：把大生态规模页降为背景；前移平台具体交付与可验证差异；增加按真实单笔贡献倒推订单门槛；增加商家资源保护、分阶段合作和退出说明。正式价格只在政策统一后填入。
