# 蝴蝶生活｜业务梳理与30天推进计划

2026年11月11日 · V0.1 · 内部工作文件

## 先明确下一步

先用重庆的少量商家，证明“套餐有吸引力—渠道能成交—到店能核销—资金能结算—各方有收益”，再用真实结果招城市合作伙伴。会议已经反复指出“品太少”“系统仍在内测”“要先有案例”。眼下最需要的不是全国铺开，而是一套能带着跑商家的说明、统一报价口径和真实订单证据。

本文件中的试点数量、时间表与继续/暂停条件是本次整理提出的建议，不是会议已批准政策，也不是业绩预测。两套外部演示定位为合作沟通版；可用于需求访谈，收费招商前仍需完成政策定稿和真实演示。

## 1. 一句话定义

蝴蝶生活拟以小程序承接本地套餐交易，联合本地服务商、商家与内容推广者，通过视频号、微信内容及分享渠道发现用户，完成购买、核销、结算与自愿复购。

- 对商家：增加一个可核算的获客渠道，先从一个适合门店履约的套餐试起。
- 对城市伙伴：把已有商家资源和运营能力转化为持续的商品经营收入。
- 对消费者：商品、使用限制、优惠与售后清楚，买后能够顺利使用。
- 对平台：提供商品和订单工具、核销与结算对账能力；从实际服务获得收入。

商家属于B端，消费者才是C端。本次材料统一使用“商家合作”称谓，避免混淆。

## 3. 商业结构：三个经营环节，一个订单证据链

**供给**：本地伙伴谈商家 → 明确套餐、售价、结算价、库存和可用时段 → 审核后上架。

**销售**：内容带货、平台或商家直播、图文入口、朋友圈社群、其他渠道转介。每个入口分别记录成本和订单来源，不能把平台总用户量当成项目可触达人数。

**履约**：消费者购买 → 预约/领券 → 商家核销 → 售后处理 → 按合同触发结算 → 商家、推广者、伙伴、平台分别对账。

**证据链**：渠道标识 → 唯一支付订单号 → 业务订单号 → 券码/核销记录 → 退款记录 → 分账流水 → 收款回单。多渠道同步只汇总一次真实交易；测试单、0元兑换单、退款单单独标记。

### 两条交易路径要分别验证

| 项目 | 路径A：视频号商品/直播带货 | 路径B：内容或广告进入小程序 |
|---|---|---|
| 用户入口 | 短视频商品卡、橱窗或直播间商品 | 实际支持的小程序链接或广告入口 |
| 商品与交易 | 会议称经同程小店等渠道承接；具体主体与页面待验证 | 小程序内购买；具体经营及支付主体待验证 |
| 成本 | 导图提到6%及达人佣金，费基、包含项、适用类目待核 | 支付费、分享佣金；若投广告还需计入获客成本 |
| 售后 | 按该订单所在渠道规则办理并同步状态 | 按小程序交易规则办理；外部兑换单须关联原交易 |
| 复购 | 在规则允许且用户自愿的条件下形成再次触达 | 自愿订阅/关注/分享，不等于已经加群或形成私域关系 |

“公域点击进入小程序”只是一次访问，不等于留存。复购应单独衡量。付费广告也不能写成零成本流量。贴图的产品名称、频率限制、挂链资格均待账号实测。

## 4. 第一批产品怎么选

建议优先：酒店自助餐、家庭聚餐/大桌菜、履约标准清楚的景区温泉票。匹克球可作为小范围补充。具体名称（包括记录中的“冰乐宝轩”“连采森林”）先向联系人核对，不能当作已签约商家。

每个候选品先检查五件事：

1. 商家能赚：结算收入扣除食材、耗材、增量人工等后仍有贡献，不能只靠后续加菜补亏。
2. 用户愿买：同内容、同时间、同限制下有可解释的价格或体验优势；不要求全网最低。
3. 内容好讲：一句话说清适合谁、包含什么、在哪用、什么时候能用。
4. 履约可控：高峰库存、预约、节假日、儿童收费、加价项目提前写明。
5. 渠道有空间：扣除全部渠道、支付、佣金和变动费用后，各方仍有正贡献。

建议首轮只选3～5家商家、每家1～2个套餐；先集中一个商圈或可服务范围。这个数量是执行设计，不是现有库存。

## 5. 单笔账必须先跑通

统一用“可分配贡献”表达分成基数，避免把售价减结算价直接称为纯利润。

可分配贡献 = 实收售价 − 商家结算 − 渠道服务费 − 支付费 − 推广佣金 − 订单补贴 − 已约定的变动服务成本 − 实际退款/赔付损失。

同一笔费用不能重复扣。支付费是否已含在渠道费内、渠道按实付还是原价计费、退款是否退费，均按实际合同填写。月度净收益还要扣固定人员、差旅、房租、税费等。

**纯假设演示，非收费政策、非实际案例：**消费者实付189元，商家结算160元，达人佣金9元；假设渠道费6%、支付费0.3%且二者分别收取，变动服务成本1元，则可分配贡献为189−160−9−11.34−0.567−1=7.093元，展示为7.09元。若平台分20%，平台约1.42元，伙伴约5.67元，双方仍需承担各自固定成本与税费。

同样假设下，小程序自然分享不发生6%渠道费，则可分配贡献18.433元；如广告引流每笔花12元，则只剩6.433元。三条渠道不能共享一套毛利判断。

若把售价改成180元而其他参数不变，视频号路径贡献为−1.34元，越卖越亏。按这些假设，保本售价约为182.50元（170÷0.937），仍未覆盖固定成本与税费。

原记录“200元扣30%后结算160元”算术不成立：扣30%是140元，160元相当于扣20%；399−350是49元价差，不能直接称为净赚40元。这两处已从对外话术中纠正。

### 建议的继续条件

商家端先有至少2家愿意续试；累计至少30笔非关联方真实付费订单，并有至少20笔完成核销及约定结算，用于暴露基础问题，不能把这个小样本称为模式已验证。按商品使用周期设置观察窗口，长有效期券不在未到期时强行判核销差。

订单—核销—结算能逐笔勾稽；已到期应结算款全部按约完成；至少一条可重复渠道在扣足变动费用后贡献为正；未解决售后都有责任人和处理时限。形成“愿续约的商家＋愿持续推的伙伴＋可解释的每单利润”，才建议扩大。

### 建议的暂停条件

真实到账或退款链路不清时暂停该路径新交易；连续两轮调整后单笔贡献仍为负，停止该品该渠道推广；商家无法履约立即停售；关键收费口径未统一时不收代理费；只靠代理费而没有真实商品交易时不扩城。预算需先填入获客、差旅、补贴、技术、客服上限，未填预算不安排付费投放。
