# 蝴蝶生活 A + C 页面细化规范

2026-11-15。用户已选择以 A 为基础，吸收 C 的价格条和折扣标签。本轮交付视觉设计，不修改小程序源码。

## 颜色分工

| 用途 | 色值与要求 |
| --- | --- |
| 品牌、主操作、选中导航 | #FF7A00；原有几何蝴蝶标志保持橙色 |
| 页面 / 卡片 | #F5F7FA / #FFFFFF；保持日常浏览的明亮感 |
| 标题 / 正文 / 辅助 | #20252D / #354052 / #657080 |
| 促销价格条 | #FF526B → #FF8A00，白色大价格，右侧分享入口 |
| 折扣标签 | #FFD54D 底、深棕文字；小胶囊，仅用于价格优惠 |
| 预约与服务信息 | 浅青绿底、深青绿字；图标 #14B8A6 |
| 五类入口 | 珊瑚餐饮、青绿门票、蓝色酒店、金黄娱乐、石板灰全部 |

颜色按功能分配。资产、订单状态、表单不用促销渐变。促销条、底部按钮、分类图标形成三级视觉重心；背景不铺满橙色。

## 尺寸建议

以下为 390 逻辑像素宽度的开发目标，不是对生成图的像素测量。rpx 换算为逻辑像素 × 750 / 390。

| 项目 | 建议 |
| --- | --- |
| 页面左右边距 / 卡片内边距 | 16 / 16 |
| 卡片间距 / 圆角 | 12 / 16 |
| 页面标题 | 18，600 字重，26 行高 |
| 商品标题 / 按钮 | 16，500–600，24 行高 |
| 正文 / 辅助说明 | 14 / 12，行高约 1.5 倍 |
| 详情主价 / 列表价格 | 32 / 24；货币符号降低一级 |
| 主按钮 / 次按钮高度 | 48 / 44；点击区至少 44×44 |
| 折扣胶囊 | 12 字号，22 高，横向留白 8 |
| 底部购买区 | 内容约 64 高，另加设备安全区 |
| 倒计时 | 等宽数字，22–24 高数字块，冒号留白稳定 |

价格、折扣、划线价空间不足时分行，不能压小到不可读。窄屏中分享可独立为右侧紧凑入口，但保留原操作。原生胶囊与导航按设备实测。

## 各页细节

1. 首页：五分类及三商品分页；保留今日上新/即将下线、筛选、福利群和客服。商品图保持统一比例；浮层避开价格及抢购按钮。
2. 商品详情：C 价格条含到手价、黄色折扣、划线价和分享。已售/库存与倒计时分行。服务标签青绿、门店电话与导航使用浅青绿承托。底部橙色购买按钮保持主操作。
3. 套餐：成人/双人/三人独立选择卡，选中使用橙描边、浅橙底及勾选；更换套餐按现有逻辑更新完整商品对象。费用包含按真实配置显示。
4. 地图：遵守原生 map 能力；未定位不画虚构距离；一店底部面板是演示场景。
5. 我的：普通用户与达人区分。达人资产沿用“我获得的蝴蝶币总数 / 可兑现 / 已兑现 / 兑现中 / 预收获”，不擅自改成现金收益。保留我的金库、权限化视频号绑定。
6. 下单：数量、姓名、手机、条件化日期及备注，未选中规则勾选框，固定合计与确定支付。其他身份证/地址分支继续由字段决定。
7. 订单：全部、待付款、拼团中、待使用、已完成五状态导航；整卡点击，不增加源码没有的快捷支付/退款按钮。

## 状态与实现边界

加载、空数据、失败重试、售罄、未开售、已结束、未上架、已下架必须保留；状态不是只改变按钮颜色，需展示对应文字。规则和资质不得因画面高度省略。图中长文为滚动区域节选，实施时仍显示完整内容。

本轮覆盖六条核心路由、九个主要页面状态，不代表全部 82 条注册路径。普通商品详情、套餐、说明底部属于同一路由。新增图形风格是建议资产，AI 图中的地图和商品照片不作为正式可发布素材。

对照依据：随包源码映射与数据口径清单。页面结构来自本地代码，数据来自历史截图及明确演示值。未连接后台，未运行微信开发者工具，未进行支付、真机或无障碍实测。
