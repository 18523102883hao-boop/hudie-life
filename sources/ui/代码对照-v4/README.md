## 这版依据什么制作

1. 上传的 wxapp_clean.zip 原生微信小程序源码。
2. 用户提供的蝴蝶生活页面截图及橙色几何蝴蝶品牌图。

## 已落实到画面的主要调整

- 以品牌橙、奶油白和深色文字替换原来混用的蓝色、红色和大面积橙底。
- 首页继续采用五类入口、三个商品一组的轮播，保留公众号、福利群和客服入口。
- 详情页保留“立即分享”，拆开销量/库存与倒计时，减少窄屏挤压；继续展示原有购买、门店导航、电话和合作入口。
- 套餐有明确的选中状态。长说明采用正常文字层级，不依赖装饰性大标题图片。
- “我的”区分普通用户和达人，保留达人资产、团队、邀请码及视频号绑定等条件入口。
- 下单保留数量、总价、条件表单、须知及同意勾选。订单列表沿用真实的五个筛选项。

## 数据与验证边界

图中的景区、价格、划线价等来自历史截图示例，不代表当前在售价格或库存。销量、剩余量和倒计时为静态设计示例；达人资产和订单数据为演示数据，没有查询真实账户。

图片为 AI 生成的视觉提案，适合确认风格和布局。图片像素尺寸与单屏缩放不同，不能直接量 PNG 像素当作开发尺寸；文案、尺寸、条件逻辑以本文档包和源码为准。图 03、06 的长说明仅展示排版节选，开发时必须保留完整内容。

已查看六张成图的排版与关键入口。尚未修改或运行小程序，没有进行微信开发者工具真机预览、接口联调、付款测试或生产验收。服务端图片、商品配置、海报模板和实时数据未验证。

## 开发人员阅读顺序

1. [源码对照与页面映射](01-源码对照与页面映射.md)：先确定改哪些页面、保留哪些条件和动作。
2. [视觉尺寸与开发交接](02-视觉尺寸与开发交接.md)：统一颜色、文字、间距、按钮与安全区。
3. [数据口径与待确认事项](03-数据口径与待确认事项.md)：先确认折扣、销量和库存等含义，再改业务展示。
4. [AI 出图提示词](04-AI出图提示词.md)：后续继续设计时保持同一约束。
5. `manifest.json`：文件尺寸、校验值和来源记录。

## 确认后再进行的工作

先确认品牌色、价格条、分类图标风格和整体密度；再制作可交付的独立图标文件、选中/未选中状态及素材清单，然后实施页面代码改造。本包中的图标是视觉方向，尚不是开发可直接引用的独立图标资产。
