# 蝴蝶生活 UI v3｜评审与开发尺寸规范

版本：2026-11-14。状态：视觉沟通稿，待用户确认；尚未修改小程序代码、后台配置或线上页面。

## 1. 本轮改动

保留橙色几何蝴蝶 LOGO、奶油底色与本地生活定位，重点参考享库生活的信息组织：售价和划线价并列、折扣标签、销量与库存、独立倒计时、套餐分组、吸顶内容导航、门店信息、固定购买栏。首页、列表、详情的营销字段使用同一套层级，不再为了留白删掉用户关心的促销信息。

页面覆盖：首页、首页商品列表、吃喝玩乐地图、我的、商品详情首屏、套餐选择、购买须知、图文详情与合作入口、订单空状态建议。03、04沿用 v2，其余为本轮修订。效果图中的景区图片包含 AI 概念图，正式页面替换为商家授权素材；地图为布局示意，实际仍接现有地图组件。

## 2. 设计基准与优先级

以 **390 逻辑 px 宽**建立尺寸。设计稿中的 px 指逻辑像素，不是 PNG 物理像素。小程序按 750rpx 宽换算：rpx = 逻辑 px × 750 ÷ 390；1 逻辑 px 约为1.923rpx。不要把导出图片的像素当布局尺寸，也不要不分基准统一乘2。

执行优先级：真实业务字段与平台原生控件 > 本文尺寸及状态规则 > 独立单页效果图 > 总览缩略图。生成式效果图用于确认视觉方向，不能视作逐像素施工图；字号、色值、按钮尺寸最终由本规范统一。

状态栏、导航栏及微信右上胶囊保留原生行为，运行时读取安全区和胶囊位置；不写死图中的9:41或设备边距。

| 促销价格带 | #B75B08 → #A84C00 | 轻渐变、白字；不可换成亮橙底小白字 |

#B45609 与白色的计算对比度约4.91:1；促销带两端与白色约4.65:1、5.68:1。这是色值计算，不代表对生成 PNG 每个像素或小程序运行界面的测量。落地时统一使用上述色值；旧图中近似橙色不要逐张取色。

中文用系统无衬线字体（iOS优先 PingFang SC，Android跟随系统），正文400、强调500、标题/价格600；不把整页都做粗体。金额和倒计时采用等宽数字特性，避免数字变化时抖动。不额外购买或引入未经授权字体。

## 4. 核心促销组件

展示顺序：商品名 → 售价／折扣／划线价 → 已售／剩余／结束倒计时 → 商品标签 → 使用提醒 → 适用门店。首屏优先保证这些内容读得清楚；套餐、须知和图文随页面下滑展示。

| 元素 | 尺寸／行为 |
|---|---|
| 详情价格带 | 390px视口时宽358px；最小高68px；左右内距16px；窄屏、长金额可增高 |
| 价格区与品牌区 | 价格优先；右侧品牌可缩为小LOGO，不能挤掉折扣和划线价 |
| 划线价 | 13px；与售价间距8px；若后台仅证明“参考价”，不能擅自标“原价” |
| 折扣标签 | 12px；行高18px；水平内距6px；垂直内距2px；与参考价间距6—8px |
| 数据行 | 距价格带12px；字号12px；销量/库存一组、倒计时一组，组间至少12px |
| 倒计时块 | 时、分、秒各22×22px；圆角4px；白字深炭底；块间冒号独立 |
| 天数 | 正常文字“15天”；超过两位天数时允许数据行变两行 |
| 标签 | 字号12px；图标14px；高度至少24px；多标签自动换行 |
| 标签真实性 | 免预约、退款、保障、补贴等仅在当前商品确实支持时展示；不能当通用装饰 |

首页上新卡保留主价、划线价、折扣与销量；两列卡比原三列留出更清楚的名称与价格空间。商品列表可展示剩余与倒计时；图示三张卡是同一商品三种套餐的静态排版样例，不代表实际三个独立活动各有1000件库存。实际展示范围以后台的商品或SKU定义为准。

售价例：¥928；参考价例：¥1074；折扣例：8.6折。金额不得因纯视觉优化舍去有意义的小数。若出现¥191.30，按统一金额格式显示，不手工写死无小数模板。

底部栏用布局预留真实高度，正文底部留出“栏高度＋安全区＋12px”；不要靠悬浮层盖住内容。商品详情使用购买栏；首页、地图、我的使用三个主导航，二者不同时出现。

固定栏视觉应统一。图中个别按钮有细微渐变差异，开发统一用#B45609实色与上述尺寸。按下态用更深一档颜色；加载时防止重复提交；售罄/结束不沿用可购买按钮外观。

## 6. 套餐与详情滚动

套餐使用纵向选项：套餐名称、内容摘要、售价、参考价、折扣、已售；选中态同时有橙色边线、浅奶油底和勾选，不能只靠颜色。费用包含按名称与数量对齐，不把冲突金额放进“价值合计”。

选择套餐后，顶部售价、参考价、折扣、库存口径、费用包含、底部按钮价、下单确认页必须同步；点击时再由后台校验价格与库存。三张选项不应各自拥有互不关联的硬编码倒计时。

吸顶锚点使用“套餐内容／购买须知／图文详情”，点击滚动到相应位置，并扣除导航栏和锚点高度；滚动时选中态随区域变化。图文预览折叠时保留真实“展开查看全部”入口，展开后可收起。福利群、商家合作、资质、使用说明、退改规则入口需要逐一接真实页面；没有目标页面的入口暂不发布。
